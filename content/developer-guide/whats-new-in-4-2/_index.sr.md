LibreSCRS 4.2 је друго функционално издање у 4.x циклусу. Додаје Qt-free
API за снимак листе читача и помоћне приступнике за податке картице,
**замењује** 4.1 PKCS#11 attach C ABI аутоматским моделом дељења сесије
унутар процеса, заокружује координацију безбедне размене порука између
читача и пролази кроз RAII / безбедност при изузецима / хигијену површине
API-ја. ABI је адитиван у односу на 4.1.0 (без ломова унутар капије
видљивости); тестне површине се више не извозе SDK потрошачима.

Хостови само за приказ који користе `LibreSCRS::Plugin`,
`LibreSCRS::Signing` и `LibreSCRS::Trust` граде се и раде непромењено.
Једина прекидна промена је уклањање 4.1 PKCS#11 attach C ABI-ја — види
[Прелазак са 4.1](#прелазак-са-41).

## API за снимак листе читача

`LibreSCRS::SmartCard::MonitorService` добија
`subscribeReaderList(ReaderListCallback)` / `unsubscribeReaderList(...)`,
који испоручују цео снимак листе читача после промене (плус иницијално
окидање за оне који се касно прикључе). Потрошачи више не преклапају
појединачне `ReaderAdded` / `ReaderRemoved` догађаје у локални `std::set`
да би повратили чланство. API је Qt-free и адитиван постојећем `subscribe`
току по догађају. Види [API за снимак листе читача](../monitor-reader-list/).

## Qt-free приступници за CardData

`LibreSCRS::Plugin::textValue(data, groupKey, fieldKey)` и
`textValueAt(data, groupIndex, fieldKey)` сажимају плес
`findGroup → groupAt → петља поља` над `CardData` у један позив који враћа
`std::optional<std::string>`. GUI адаптери (LibreCelik сада; LibreMac /
LibreKDE следећи) постају танки `QString` омотачи изнад њих. Види
[Помоћни приступници за CardData](../card-data-access/).

## Дељење сесије унутар процеса замењује attach C ABI

4.1 PKCS#11 attach C ABI — `AttachHook.h`
(`librescrs_pkcs11_attach_session` / `_detach_session`, токен
`LibrescrsPkcs11AttachTokenV1`) и C++ омотач
`LibreSCRS::Pkcs11::SessionAttachment` — **је уклоњен**. У 4.2,
`CardSession` наслеђује `std::enable_shared_from_this`; поседовање сесије
кроз `std::shared_ptr<CardSession>` је аутоматски региструје у
процес-локалном `SessionPresence` регистру (`weak_ptr` који RAII брише).
opensc-pkcs11 провајдер унутар процеса консултује тај регистар и
**одустаје** — одбија да отвори паралелну PC/SC конекцију — када на читачу
већ постоји жив PACE/BAC канал безбедне размене порука, тако да потрошач
потписивања унутар процеса поново користи живу SM хоста уместо да покрене
конфликтно друго руковање. Више нема експлицитног attach/detach позива.
Види [Дељење сесије унутар процеса](../pkcs11-session-injection/).

## Очвршћавање конкурентности

4.2 циклус очвршћава површину конкурентности `MonitorService`-а / интерног
`Monitor`-а уз детерминистичке регресионе тестове без хардвера:

- **Трка иницијалног окидања** — `subscribeReaderList` регистрован после
  `subscribe`-а по догађају могао је испоручити празан снимак пре првог
  набрајања нити; сада зависи од засуна `initialPollComplete` па редослед
  регистрације не утиче на исправност.
- **Животни циклус претплате + сажимач** — затворена TOCTOU која је
  остављала сирочад интерну претплату (цурење нити за испитивање + отворен
  PC/SC контекст); `unsubscribe(Drain)` отпушта браву испоруке пре спајања
  нити; сажимач потискује застарео `CardInserted`/`CardRemoved` за читач
  уклоњен током прозора пражњења.
- **Заштита од реентрантности CardSession-а** — позивање методе
  `CardSession`-а на нити која држи `ActiveChannelHolder` раније је
  самозакључавало; `activateChannelWithSm` / `activateChannelFor` сада
  враћају `ChannelActivationError::ReentrantAccess` уместо блокирања.

## Картице и додаци

- **AET SafeSign QSCD (Infineon)** — PKCS#15 додатак откључава AET SafeSign
  QSCD картице кроз PUT DATA размену софтверске атестације, па читање и
  потписивање сада раде на овим картицама.
- **Одбијање страног пасоша преко SM** — испитивање PKCS#15 аплета ради
  умотано у SM и разликује присутан аплет (`0x9000`) од одсутног
  (`0x6A82`), па се страни ICAO пасоши на живом SM каналу уредно одбијају
  уместо да буду погрешно везани.

## Паковање и хигијена

- **Потпуност лиценци у пакету** — LibreCelik испоручује манифестом вођену,
  fail-closed проверу лиценци пакета: свака дељена библиотека у пакету мора
  да се пресликава на документовану лиценцу (покрива Linux `.so` и macOS
  `.dylib` распореде), наметнуто у CI-ју при сваком пушу.
- **RAII / безбедност при изузецима / хигијена API-ја** — нови RAII омотачи
  за OpenSSL, OpenSC, PC/SC контекст и `dlopen` хендлове; пролаз кроз
  noexcept-allocation уговор; минимална јавна површина API-ја са политиком
  наметнутом из CMake-а; тестне површине за убацивање иза
  `LIBRESCRS_INTERNAL_BUILD`, више не у SDK-видљивом извозном скупу.

## Прелазак са 4.1

- **Хостови само за приказ:** нису потребне промене.
- **Хостови који уграђују `librescrs-pkcs11.so` унутар процеса:** уклоните
  сву `SessionAttachment` / `AttachHook` инсталацију. Поседујте живу сесију
  као `std::shared_ptr<CardSession>` и предајте је потрошачу унутар процеса
  (нпр. `SigningService::sign`); поновна употреба SM сада се дешава
  аутоматски преко `SessionPresence`. Види
  [Дељење сесије унутар процеса](../pkcs11-session-injection/#прелазак-са-41).
- **Праћење читача:** замените свако ручно преклапање `std::set`-а над
  појединачним догађајима са `subscribeReaderList`.
- **GUI / адаптери података картице:** делегирајте тражење поља
  `LibreSCRS::Plugin::textValue` / `textValueAt`.
